# M120 多旁支布局 HOST 原型 v403

全局请求上限要求为 64。本原型仅扩展小批次的四步主干，使每个请求最多保留四个不同的旁支叶子；固定 target M120/S24 和 1792 个复制位置。请求数、候选数、主干加旁支分组数、真实复制量分别受限，不能只按候选数判断能否放入计算图。

通过 CPU 上 180 个旧单旁支等价用例和 319 个多旁支复制/可见性用例，并拒绝分组或复制越界。测试使用实际树计划、mask 与布局函数；没有构建模型或启动 NPU。

这还不是生产候选。需要实现实际 typed 分配与整票资源控制、请求长度与 KV 预留一致性、未验证 eager 父节点排除，再完成独立模型/全部 KV 检查、优化 draft 实际耗时和完整负载 own-AR。没有 Raw、Goodput 或免费提速结论。当前正在运行的完整实验仍是 v402。
